# Compared with other tools

| Tool | Searches | How |
|---|---|---|
| anygrep | notes, PDF pages, images | local multimodal model, CLI, no server |
| rclip | images | local CLIP model, CLI |
| semtools | text documents | local embeddings; PDF parsing uses a cloud service (LlamaParse) |
| sist2 | many file types, with OCR | self-hosted server with a web UI; keyword search, plus optional embeddings search |
| mgrep | code, text, PDFs, images | CLI backed by a cloud store; needs an account or API key |
| Spotlight, Windows Search | files on the machine | built into the OS; mostly keyword and metadata (semantic search on Windows 11 Copilot+ PCs) |
